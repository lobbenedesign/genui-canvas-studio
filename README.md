### 🛠️ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/lobbenedesign/genui-canvas-studio.git
cd genui-canvas-studio

# 2. Run with Bun
bun server.ts
```

Open your browser at **`http://localhost:3010`**.
